  > tanda 'GET request in background'.
Cara 2: Stream Deck > System > Open > pilih fail .bat dalam folder ni.

end-win = Menang, end-lose = Kalah, end = Game habis (W/L + tolak baki + rotation).
win / lose = tambah W/L sahaja. win-1 / lose-1 = tolak.
START_OVERLAY.bat dan overlay (OBS) atau App mesti terbuka.
kill-solo = efek SOLO KILL (SOLO_KILL.bat). Efek lain: kill-first, kill-savage, kill-maniac, kill-legendary ...
gift-hint = popup "hantar gift" keluar sekarang (GIFT_POPUP.bat).
